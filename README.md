# SOSync AI Tech IT Solution — Portfolio & Web Application

Modern Next.js 15 App Router web application built with React 19, Tailwind CSS v4, TypeScript, and Radix UI.

## Features
- **App Router Architecture**: Next.js 15 with Server & Client components for fast pre-rendering and optimal SEO
- **Complete Page Suite**:
  - `/` — Homepage (Hero, Portfolio Story, Recent Projects)
  - `/portfolio` — Full portfolio gallery with category filters & project details
  - `/our-story` — Leadership, full stack team, modern workspace tour, process, & free support
  - `/testimonials` — Client review slider & unfiltered testimonial grid
  - `/contact` — Contact details, interactive consultation form & office map
  - `/admin` & `/admin/login` — Client-side admin CMS dashboard
- **Design System**: Obsidian Dark, Tech Orange, Warm Amber, and Tailwind CSS v4 design tokens
- **Type Safety**: TypeScript 5.8 with strict checks

## Development

Run locally using npm:

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```sh
npm run build
npm run start
```
